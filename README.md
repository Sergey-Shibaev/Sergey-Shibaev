## Основной открытый проект

### Trading Execution Engine

Исполнительный модуль автоматизированной торговой системы.

Проект демонстрирует:

- проектирование архитектуры программной системы;
- контрактный подход к разработке;
- интеграцию TradingView, FastAPI, T-Invest API и Telegram;
- управление состояниями;
- безопасную обработку отказов;
- автоматизированное тестирование.

➡️ https://github.com/Sergey-Shibaev/trading-execution-engine

## Инженерный подход

> **Анализ → Требования → Архитектура → Код → Тестирование**

Убеждён, что качество программной системы определяется прежде всего качеством её проектирования. Хорошая архитектура делает систему понятной, расширяемой и сопровождаемой на протяжении всего жизненного цикла.
