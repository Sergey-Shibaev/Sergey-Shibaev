## Системный аналитик • Инженер прикладных цифровых систем

Проектирую прикладные программные системы: от анализа предметной области и формализации требований до архитектуры, реализации и тестирования.

### Основные компетенции

- Системный анализ
- Проектирование архитектуры
- API-интеграции
- Python
- FastAPI
- Telegram Bot API
- Автоматизация

### Открытый проект

#### Trading Execution Engine

Исполнительный движок алгоритмической торговли.

Проект демонстрирует:

- контрактный подход к разработке;
- проектирование архитектуры;
- интеграцию TradingView, FastAPI, T-Invest API и Telegram;
- управление состояниями;
- безопасную обработку отказов;
- автоматизированное тестирование.

➡️ https://github.com/Sergey-Shibaev/trading-execution-engine
